# CodeAlpha Task 4 - Sales Prediction using Python

## 📌 Project Overview

This project focuses on predicting product sales using machine learning techniques in Python.

The model analyzes advertising expenditure across different media channels and predicts the expected sales. This helps understand how advertising investments influence sales and supports data-driven decision making.

## 🎯 Objective

The main objectives of this project are:

- Analyze the relationship between advertising expenditure and sales.
- Build a machine learning model for sales prediction.
- Train the model using historical advertising data.
- Evaluate the prediction results.
- Visualize actual and predicted sales.
- Understand the impact of different advertising channels on sales.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Linear Regression
- Git & GitHub

## 📊 Dataset

The project uses the `advertising.csv` dataset.

The dataset contains advertising expenditure for:

- TV
- Radio
- Newspaper

and the corresponding:

- Sales

The dataset is used to train the machine learning model and predict sales values.

## 🤖 Machine Learning Algorithm

### Linear Regression

Linear Regression is used to model the relationship between the input advertising features and sales.

The model learns the relationship between advertising expenditure and sales from the training data.
